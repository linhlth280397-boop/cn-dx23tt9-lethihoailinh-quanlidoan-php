## Tuần 5 - 7: Hoàn thiện hệ thống và chuẩn bị báo cáo đồ án

- Tiếp tục hoàn thiện các chức năng của website quản lý đồ án bằng PHP và MySQL.
- Kiểm tra, chỉnh sửa giao diện và tối ưu quá trình xử lý dữ liệu trên hệ thống.
- Hoàn thành xây dựng website demo phục vụ cho việc báo cáo và chạy thử hệ thống.
- Bổ sung và chỉnh sửa nội dung báo cáo đồ án trên file Word:
  - Hoàn thiện chương phân tích và thiết kế hệ thống.
  - Cập nhật hình ảnh giao diện và mô tả chức năng.
  - Rà soát và chỉnh sửa nội dung tổng thể báo cáo.
- Thiết kế và hoàn thành slide PowerPoint phục vụ báo cáo đồ án.
- Tổng hợp source code và cập nhật tài liệu lên Github để lưu trữ và quản lý phiên bản.

### Kết quả đạt được

- Hoàn thành cơ bản website demo của hệ thống quản lý đồ án.
- Hoàn thiện file báo cáo Word và slide thuyết trình.
- Hệ thống có thể thực hiện các chức năng chính như:
  - Quản lý đề tài
  - Quản lý sinh viên
  - Quản lý giảng viên
  - Theo dõi tiến độ đồ án
